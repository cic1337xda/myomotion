Privacy Policy & Data Security

Last updated: October 2026 • Compliant with Clinical Research Standards

1. Biometric Data Collection

MyoMotion collects real-time upper-limb kinematics (elbow flexion angles and wrist curl sagittal pitch) and surface electromyography (MyoWare 2.0 sEMG voltages and %MVC) strictly for therapeutic rehabilitation biofeedback.

2. Cryptographic Storage & Token Architecture

All authentication tokens are transmitted exclusively inside encrypted, server-side HttpOnly, SameSite=Lax cookies. Tokens are strictly shielded from client-side JavaScript to eliminate Cross-Site Scripting (XSS) risks.

3. Data Ownership & Authorization Enforcement

Every database transaction executes parameterized queries via SQLAlchemy ORM. Server-side access control guarantees clinicians and patients can only access devices and rehabilitation logs linked to their authenticated account.

4. Multi-Factor OTP Verification

Account creation and password recovery require 6-digit one-time authorization codes dispatched via the Resend API from myomotion@mail.flowkraft.xyz. OTP codes expire automatically within 5 minutes.
